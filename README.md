# Не пиши голосовое! — сайт

Статический лендинг приложения **«Не пиши голосовое!»** — Android-приложения для голосовых заметок с локальным распознаванием речи на русском языке.

Временный адрес (GitHub Pages): `https://baslie.github.io/negolosom-site/`
Собственный домен будет подключён через `CNAME` позже.

## Что делает приложение

- Записывает голосовые заметки на Android и превращает их в текст прямо на телефоне.
- Работает офлайн: звук никуда не уходит, аккаунты не нужны.
- Под капотом — [GigaAM v3 от Сбера](https://github.com/salute-developers/GigaAM), модель для русской речи. Средний WER 8,3 % на 10 публичных бенчмарках, в 2,5× точнее Whisper-large-v3 (по данным `evaluation.md` Сбера, релиз ноябрь 2025).
- Расшифровка лежит рядом с аудио: редактируется, копируется, шарится в любой мессенджер.
- Версия для iOS — позже.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `index.html` | Одностраничник: hero, три плитки-возможности, футер |
| `logo.svg` | Логотип-птичка, он же `favicon` и `og:image` |

Без сборщика и зависимостей. Чистый HTML + CSS. Шрифты Source Sans 3 и Caveat подгружаются из Google Fonts.

## Запуск локально

Двойной клик по `index.html` — страница откроется в браузере. Или поднимите любой статический сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

## Деплой

Проект рассчитан на GitHub Pages из ветки `main`, корень репозитория. Своё доменное имя прикрепляется через добавление файла `CNAME` в корень + настройка DNS у регистратора.
